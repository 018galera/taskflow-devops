# 🚀 TaskFlow — Projeto DevOps

Sistema de gerenciamento de tarefas com pipeline DevOps completo (CI/CD, testes automatizados, IaC e monitoramento).

## 📚 Stack

| Camada | Tecnologia |
|---|---|
| Frontend | React + Vite |
| Backend | Node.js + Express |
| Banco | SQLite (dev) / PostgreSQL (prod) |
| Testes | Jest + Supertest |
| CI/CD | GitHub Actions |
| Deploy | Vercel (front) + Railway (back) |
| IaC | Docker Compose |
| Monitoramento | UptimeRobot + logs |
